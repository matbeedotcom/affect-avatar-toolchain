# Affect Calibration Toolchain

Offline ML pipeline that produces the trained artifacts the runtime affect
pipeline depends on:

1. `whisper_to_vad.onnx` — speech-emotion regressor mapping Whisper encoder
   embeddings to (valence, arousal, dominance).
2. `llm_directions/{model}_layer{N}.npz` — direction matrix `D ∈ ℝ^{k × d_llm}`
   projecting affect coordinates into the LLM's hidden-state subspace.
3. `manifest.json` — calibration ID binding artifacts to specific
   `(LLM hash, layer, Whisper, dataset)` tuple. Runtime refuses mismatches.

**This is a Phase 0 skeleton.** Phase 5 fills in the scripts, datasets, and
training logic. See
[`docs/references/activation-steering-audio-llm/PROJECT_PLAN.md` §6 Phase 5](../../docs/references/activation-steering-audio-llm/PROJECT_PLAN.md)
and
[`docs/references/activation-steering-audio-llm/IMPLEMENTATION_PLAN.md` §4](../../docs/references/activation-steering-audio-llm/IMPLEMENTATION_PLAN.md)
for the planned scripts and outputs.

## Datasets

**Phase 5 uses a commercial-clean dataset stack.** Per the pivot recorded in
[`docs/references/activation-steering-audio-llm/notes/spike-d-datasets.md` §"Pivot — commercial-clean dataset shortlist"](../../docs/references/activation-steering-audio-llm/notes/spike-d-datasets.md):

- **Primary training**: [`yhaha/EmoVoice-DB`](https://huggingface.co/datasets/yhaha/EmoVoice-DB)
  (MIT, synthetic, 22k samples, ~40 h) plus
  [`myleslinder/crema-d`](https://huggingface.co/datasets/myleslinder/crema-d)
  (ODbL, human, 91 actors, ~5 h).
- **Held-out validation**: a speaker-disjoint slice of CREMA-D actors plus
  JL-Corpus (CC0).
- **Categorical → VAD mapping**: auto-generated `contrast_pairs.jsonl`
  produced by `scripts/02b_generate_contrast_pairs.py` from 3 hand-authored
  trait descriptions (one per VAD axis). Generator follows the persona-
  vectors pipeline of Chen et al. 2025
  ([arXiv:2507.21509](https://arxiv.org/abs/2507.21509); see
  [`docs/.../notes/spike-f-persona-vectors-pipeline.md`](../../docs/references/activation-steering-audio-llm/notes/spike-f-persona-vectors-pipeline.md)):
  per axis, an elicitation LLM produces 5 positive + 5 negative system
  prompts × 40 evaluation questions = 400 rows per axis (full cartesian
  product per pole: 5×40 positive + 5×40 negative). Three axes × 400 =
  1200 rows total. Reproducible from the trait
  descriptions; replaces the hand-authored sentence list and the NRC-VAD
  commercial-licensing question.
- **Optional cross-lingual augmentation**: SUBESCO (Bangla, CC BY 4.0) and
  Emozionalmente (Italian, CC BY 4.0) for speaker-pool diversity.

The earlier MSP-Podcast / IEMOCAP recommendations are research-only and
**not used** under the commercial-deployment posture; they are preserved
in the spike memo for reference in case the deployment intent changes.

## Reproduction (Phase 5)

To be filled by Phase 5. Will look approximately like:

```bash
cd tools/affect_calibration
uv sync                                          # or poetry install
huggingface-cli download yhaha/EmoVoice-DB --repo-type dataset \
    --local-dir data/emovoice_db
huggingface-cli download myleslinder/crema-d --repo-type dataset \
    --local-dir data/crema_d
./scripts/01_extract_whisper_embeddings.py --dataset emovoice_db
./scripts/01_extract_whisper_embeddings.py --dataset crema_d
./scripts/02_train_vad_regressor.py --output artifacts/whisper_to_vad.onnx
./scripts/02b_generate_contrast_pairs.py \
    --trait-descriptions data/trait_descriptions.json \
    --elicitation-model "$ELICITATION_LLM" \
    --output data/contrast_pairs.jsonl
./scripts/03_extract_llm_directions.py \
    --model "$LLAMA_MODEL_PATH" --layer 18 \
    --contrast-pairs data/contrast_pairs.jsonl \
    --output artifacts/llm_directions/qwen3-27b_layer18.npz
./scripts/04_validate_pipeline.py --report artifacts/calibration_report.md
```
